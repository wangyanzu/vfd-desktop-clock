# M202MD28AA 桌面外壳 V1

本版将“屏幕略微”解释为屏幕相对竖直方向后仰 15°（与桌面 75°）。横向长条、深灰色前壳、独立托架，可拆后盖。`preview.png` 由实际实体模型生成；文字仅示意内容。

## 手册依据

源文件：`../../docs/M202MD28AA_A.pdf`。

- PDF 第 4 页（印刷页 1）：模块 215±1 × 50±1 mm，厚度最大 26.3 mm，显示区 160.5 × 23.9 mm。
- PDF 第 28 页（印刷页 25，图 1）：四孔直径 3.5±0.3 mm，孔距 207±0.5 × 42±0.5 mm；PCB 名义厚度 1.6 mm；玻璃前表面相对 PCB 前侧约 12.2 mm。
- 图 1：显示区左侧距 PCB 左缘 23.25 mm、下侧距 PCB 下缘 9.05 mm，因此显示中心相对 PCB 中心向左、向下各 4 mm。按手册图示观看方向；实物装反需调整。
- 图 1 对 FG 区域有限制。立柱仅使用四个原安装孔，不沿 PCB 边缘添加夹条，不接触玻璃及玻璃排气部位。

## 文件与验证

- `enclosure.scad`：参数化源模型，可选择 `body`、`lid`、`stand`、`assembly`、`exploded`。
- `body.stl`、`lid.stl`、`stand.stl`：毫米单位；后盖已经翻至平板贴平台、立柱朝上。
- `build.py`：与 SCAD 对应的 Python 实体构造、STL 导出、几何检查和预览生成；修改源参数后也要同步修改此脚本再导出。
- `validation.json`：三件模型均通过封闭网格、法向一致、正体积及单一连通实体检查。

本机 OpenSCAD 可执行文件因 Qt/处理器指令集不兼容无法启动，故 STL 使用 Manifold 实体布尔运算导出；未进行 OpenSCAD 渲染验证。源文件与 Python 几何规格对应。预览不代表实物配合验收。

重新生成：Python 环境安装 `numpy manifold3d trimesh Pillow` 后运行 `python build.py`。默认字体路径适用于 macOS，其他系统需改字体路径。

## 打样与装配

1. 先打印后盖/孔位样件，核对四孔、元件避让、玻璃朝向和改装线束；不要先整套量产。
2. 暂按 M3 塑料自攻螺钉设计：立柱导孔 2.6 mm，后盖通孔 3.4 mm。屏幕侧可从 M3×6、配绝缘垫片试装；后盖侧从 M3×8 试装。实际有效咬合深度和螺钉头直径需实测，不能压住玻璃或元件。
3. 把屏幕背面放到后盖四根立柱上，从屏幕正面原孔拧入，屏幕与后盖形成一个组件，再从前壳后方装入。玻璃前表面与前壳内面名义间隙约 2.7 mm。
4. 后盖用四颗独立螺钉固定至前壳，线束经后下缺口引出。底座为放置式托架，可贴薄泡棉减小晃动；未设计锁扣，搬运时托住底座与壳体。
5. 底座四个直径 10 mm、深 0.8 mm 的底部凹位用于粘橡胶脚垫。

打印起点：0.2 mm 层高、至少 3 道壁；后盖和底座平放。前壳前面朝下，但四个后盖螺柱跨过前窗以外区域，仍需切片检查局部悬空与支撑。232 mm 长件需核对打印机有效平台及裙边空间。材料与打印温度按材料规格设置；本版未做热测试。

## 尚需实测再定稿

- 当前固件使用改装 UART 屏，原手册连接器不代表实物接口。12×8 缺口是通用引线口，尚不是 USB-C/电源座精确开孔。
- ESP32-C3 和 AHT10 实物模块尺寸、焊针方向、按键型号未提供。本版未建立其固定柱、专用按键孔和插座孔，不能视为全套电子元件装配完成。
- 温湿度传感器应置于壳体侧外独立通风小盒，通过出线口接线；本版没有为未知传感器板建专用小盒。不要直接放在 VFD 电源后方测量室温。人体/亮度传感器面孔待型号确定后增加。
- 上/后部窄通风孔已保留，但约 4.55 W 的手册最大全亮功耗需要实机温升验证；屏幕亮度、安装方向和传感器误差都应随样机核对。
- 前窗当前开放；若增加保护片，需留出厚度与固定槽，并重新核对大视角遮挡。不要直接把镜片压在 VFD 玻璃上。
- 手册第 2 页指出内部约 58 V，断电放电约 30 秒；拆装须断电并等待，采用绝缘支撑、整理线束，不让金属件碰触电路。通风孔并非电气安全认证。
