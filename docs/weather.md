# 心知天气与室内外对比

接入心知天气 V3 实况接口 `https://api.seniverse.com/v3/weather/now.json`。网页和 VFD 并列显示室内、室外数值，不计算温差。

## 设置

1. 打开设备管理页，在“心知天气”中启用服务，填写城市、拼音或心知城市 ID。
2. 公钥（uid）和私钥（key）各选择“填写新值”，填入对应 V3 产品密钥。默认刷新间隔 15 分钟，可设 5–60 分钟。
3. 保存后，网页显示天气连接状态、城市、天气、观测时间和室内外温湿度。密钥输入清空，以后通过“保留 / 填写新值 / 清除”管理，不回显已保存内容。
4. 在“内容轮播”勾选“室外天气”和“室内外对比”，保存轮播设置。原有选择不会被天气配置自动改写。

显示示例：第二行 `OUT:18.0C CLOUDY` 或 `IN:25.6 OUT:18.0C`；第一行继续显示时间。天气或传感器从未获得有效数据时分别使用占位符，一边失败不妨碍另一边显示；旧数据保留并用 `*` 标记。网页并列显示温湿度，不输出温差数值或冷热判断。

心知免费实况可能不提供湿度，此时显示“湿度未提供”，不会填入模拟值。AHT10 无有效数据时室内值仍显示不可用，天气接入不能替代室内传感器。

## 请求与恢复

- 使用 HTTPS、框架内置 CA 根证书及 HMAC-SHA1 签名。先完成时间同步，再对 `ts=秒级时间戳&ttl=600&uid=公钥` 签名，Base64 后 URL 编码。私钥不进入天气请求 URL，不写入网页资源或日志。
- 请求位于独立 FreeRTOS 任务，等待网络不会阻塞时钟、动画或按键。响应上限 4096 字节，限制嵌套深度、字段类型、温湿度范围与观测时间；不接受重复关键字段或带尾随内容的响应。
- 普通失败至少间隔 60 秒重试，鉴权失败 / 限流至少间隔 15 分钟。成功后按配置刷新。断网或请求失败保留上次有效天气，观测时间加经过时间满 90 分钟后标记过期。
- 位置、密钥或启用状态变更后丢弃旧缓存并重新获取。过期配置对应的在途响应不会覆盖新位置的数据。
- GPIO3 人工休眠同时等待 MQTT 和天气请求退出，随后关闭网络进入轻睡眠。唤醒后恢复联网并重新请求；内存中旧天气仍标记其真实时效。
- 自动省电从上电 / 按钮唤醒计时：60 秒调暗、30 分钟关屏休眠。天气更新与网页轮询不重置计时。
- 天气设置以独立版本记录和 CRC32 存入 NVS，保存成功后才发布。沿用设备登录、同源策略、CSRF 校验和固定请求体限制。

## 验证

`node test/web_weather_test.cjs`（需 jsdom 26.1.0）覆盖编辑保留、密钥保存后清空、重复提交、CSRF、保存失败与室内外缺失 / 过期值显示。

`sh scripts/test_weather_response.sh /path/to/cJSON-1.7.19` 使用与当前 ESP32 SDK 相同版本的 cJSON 源码，验证实际响应解析，包括免费 / 完整字段、格式错误、超大响应、重复字段、未来时间和旧观测。

真实接口联调需要在设备页面填写有效 V3 公私钥与城市；上述自动测试使用明确的 fixture，不访问用户账户。
