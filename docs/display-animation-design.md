# M202MD28AA 显示能力与动画设计

核对日期：2026-10-21。依据 `M202MD28AA_A.pdf`，文档编号 AN-C-2409A。以下页码使用手册页脚的 `[n/63]`；PDF 阅读器页码为 n+3。文档指令与实物传输接口分别确认，不能因指令相同就认定接口相同。

## 已确认能力

| 能力 | 手册依据 | 工程结论 |
| --- | --- | --- |
| 20×2 字符，每格 15×16 点 | 1/63，2-2 | 以 40 个字格建模，不按字符串字节长度布局 |
| 显示一个字型，光标右移一格 | 9/63，4-2.1 | 2 字节中文编码不等于占两格；字节数和字格数分开 |
| 简体中文 GB2312、繁体中文 Big5、日文、韩文 | 9/63；22/63 | GB2312 可用于中文标题与消息；不直接发送 UTF-8 |
| 清屏、逐行清除、定位、覆写 | 8/63；12–15/63 | 主体动画仍采用主机合成与精确覆写 |
| 水平/垂直滚动模式 | 10–12/63；14–15/63 | 属于字符输入/光标到边界时的行为，不等于任意像素平移命令 |
| 四档亮度 | 16/63，4-2.22 | 25/50/75/100%；不设计为连续平滑渐变 |
| 显示电源开关 | 16/63，4-2.24 | 关屏命令为 `1F 28 61 40 00`，开屏末字节为 `01`；不等于切断外部 5V 电源 |
| 屏幕闪烁 | 16/63，4-2.21 | 周期 n×100ms；默认动画不采用全屏闪烁 |
| 反向显示 | 16/63，4-2.23 | 指令已确认；对已有字符/后续字符的影响范围需实测，不作为首批反馈效果 |
| 15×16 自定义字形 | 18/63；23/63 | 每字形 30 字节；可预注册图标和少量动画帧，不是自由绘图 framebuffer |
| 自定义字形采用 FROM | 8–9/63；17–21/63 | 写入寿命约 100,000 次，生效涉及设定模式结束或再次启动；不能逐帧下载字形或每次开机重写 |
| 原厂启动画面 | 7/63 | 软件版本、语言设定各显示约 1 秒；应用开机动画的起点需按实物就绪时序确定 |

ASCII `Frame` 按字节存储 20 列。已新增 `CellFrame` 字格模型：每格保存一个编码完整的字形（ASCII 1 字节、GB2312 2 字节），动画裁切、比较、滚动都按字格处理，最终再编码为传输字节。

## 传输接口边界

手册 3/63、24/63 明确描述 USB 2.0 HID，VID=0x1008、PID=0x101A，单次有效数据最大 63 字节；原厂 CN1 引脚为 VCC、VBUS、D−、D+、GND、FG。该文档没有给出 UART 波特率、引脚及电平规格。

用户于 2026-10-21 确认实物已自行改装，通信以原代码为准：UART1，9600 baud，8N1，ESP32 TX=GPIO0、RX=GPIO1。项目使用改装后的 UART 路径，不采用手册中的原厂 USB HID 传输封装。当前单向显示只使用 TX=GPIO0，GPIO1 未在新固件中启用；后续若需要命令回读，再按原接线启用 RX=GPIO1。

此前估算的约 10fps 仅是当前 9600 baud ASCII 传输路径的起始预算。整屏 40 个中文会占 80 个数据字节，带两行定位共 88 字节，8N1/9600 的纯线上时间约 92ms。中文整屏动画需从约 6–8fps 起实测；ASCII 单行可以更快。不能将现有 ASCII 动画预算直接套到中文整屏。

## 动画风格与场景

统一使用“揭示 / 推入 / 收拢”，静态阅读优先。所有时间为初始设计值，最终按实物吞吐、启动延迟与视觉效果调整。

| 事件 | 第一版 | 初始时长 / 规则 |
| --- | --- | --- |
| 冷启动 | 实物就绪后，中心展开品牌文字，再揭示首页 | 应用动画约 700–1000ms；原厂约 2 秒启动画面另计，不承诺可覆盖或关闭 |
| 唤醒 | 恢复显示电源及设置，两行从中心向两侧展开 | 标准 400ms、轻量 80ms，不播放品牌开机动画 |
| 睡眠 | 第二行先向中心收拢，时间行随后收拢，再发显示电源关闭 | 标准 480ms、轻量 160ms；按键可取消；排空传输后才允许 MCU 睡眠 |
| 自动换页 | 时间行保留，第二行带两格间隔向左推入，缓入缓出 | 标准 640ms、轻量 160ms；按完整字格推进 |
| 手动换页 | 同方向快速推入 | 约 160–240ms；连续操作只保留最后目标 |
| 首次内容可用 | 左到右分组揭示标签与值 | 约 240–400ms；切换动画与入场动画不叠加 |
| 数值更新 | 时间及其他数值直接更新 | 不滚动时间数字，星期在时间右侧常驻 |
| 消息到达 | 先打出 >>> NEW MESSAGE，再逐字展开正文 | 标准 900ms；正文入场并排空后才允许确认；休眠保留内存消息 |
| 长文本 | 首尾停留、分字格滚动 | 不拆 GB2312 双字节字符；换页时立即停止旧滚动 |
| 网络异常 / 恢复 | 静态状态标记，恢复时可给一次提示 | 不反复抢占整屏 |
| 配网 / OTA | 静态地址、密钥或真实进度 | 不用装饰动画妨碍读取；关键操作期间暂停睡眠与普通轮播 |

睡眠与唤醒中的电源命令已获手册确认，但关屏后的显存/设置保留情况、是否支持关屏期间写字、恢复稳定时间仍需在改装实物上实测。驱动应保留主机影子画面，唤醒后完整重绘，不依赖未说明的保留行为。

## 自定义字形的后续用途

第二阶段可预注册有限图标：温度、湿度、天气、网络、消息，以及 4–8 帧加载图标。烧写属于独立的字形安装/升级过程，只有字形资源版本改变时执行；不能作为普通刷新、冷启动或每帧动画的一部分。

需先验证字形选择/查找规则、与内置 ASCII/中文的共存、退出设定模式后的复位行为及读回校验。文档未提供普通 RAM 动态字形上传或任意像素窗口滚动接口，因此第一版不承诺像素级数字翻页、整屏像素擦除或自由位图动画。

## 实现结构与测试边界

`业务数据 -> 字格页面 -> 动画合成 -> 差分命令 -> 传输适配器`

- 动画是时间驱动的纯逻辑，不使用 delay 等待。
- 动画被打断时，从当前可见字格衔接；数据更新合并到最新目标，不堆积帧。
- 控制器限制在途字节与帧发送频率，宁可跳过过期中间帧，也不积压旧动画。
- 电源/亮度是独立控制状态；动画临时亮度不覆盖用户保存值。
- 0x00 是有效命令参数，长度显式传递，不能作为终止符或过滤掉。
- 提供关闭、轻量、标准三个动效等级；关闭动效不改变业务行为。
- 协议测试覆盖电源零参数、光标边界、编码完整性与差分；动画测试覆盖打断、数据合并、时间回绕与终帧一致。

第一版已实现字格模型、通用动画、UART 排空控制及睡眠/唤醒状态机，并接入开机和配网页切换。见 [可交互离线预览](animation-preview.html)。运行驱动使用手册已确认的电源、光标、闪烁、反向及字型选择命令，不注册字形或写入屏幕 FROM。

消息批次已接入完整 UTF-8 转 GB2312、8 条消息队列、长文本滚动与本机确认。消息占第二行，第一行保留时间及消息数量；睡眠或配网期间只缓存。首段停留 1500ms、每 400ms 滚动一个字格，末段额外停留 1200ms；确认后显示约 1 秒反馈，再显示下一条或恢复时钟。离线预览包含 9 种场景 × 3 档动效，新增实际轮播与消息打断场景。自定义图标安装尚未实现。动效等级目前通过编译配置选择，尚未提供网页配置。显示睡眠只由本机串口 `s` / `w` 事件触发，配网期间保持唤醒；没有接入人体传感器或 MCU 深度睡眠。“无人时缓存”是待传感器接入后的目标，目前仅以显示唤醒状态控制展示，不判断真实在场。消息确认要求对应页面完成入场并排空 UART，详见 [消息说明](mqtt-messages.md)。

默认初次等待 2200ms，唤醒初始化包实际排空后再等 100ms，均是可配置的待标定初值，不能视为实物时序已经验证。C++ 测试覆盖协议零参数、字格与帧边界、动画中断/数据合并、UART 忙时跳帧、睡眠排空及唤醒重绘。未执行烧录或硬件测试。


## 内容轮播接入

普通内容第一行持续显示年月、时间、星期，第二行按选择展示室内温湿度合并、独立温度、独立湿度、室外天气或室内外对比。默认室内温湿度，每页 8 秒；管理页可选择 1–5 项并将统一停留设为 5–120 秒，只选一项即固定显示。固定顺序不依赖网络数据。

轮播计时在对应页面完成入场、输出排空后才开始；数值变化不会重新播放入场。消息到达会抢占第二行，确认反馈结束后恢复原轮播页；配网和睡眠也暂停，恢复时重新提供完整停留。修改选择后从所选第一项开始，不让隐藏页面在后台跳过阅读时间。应用层使用 3–6 作为普通页键，与配网、确认及消息 ID 隔离。

预览“轮播与消息打断”由同一 `ContentRotation`、`MessageInbox` 和 `DisplayService` 合成，消息到达和确认在预览中按脚本触发。预览温湿度属于明确的演示数据；真实固件只使用 AHT10 数据。仍需实物验证动画观感与 UART 时序。

所有页面统一居中。固定内容每 5 分钟偏移一格，范围为中心左右各 2 格，按可用空白限制，避免截断。首次联网取得 IP 后显示 4 秒；日期与星期独立轮播页已移除，旧配置自动移除日期位，只有日期时回退到室内温湿度。
