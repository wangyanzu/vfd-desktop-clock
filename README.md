# VFD 桌面时钟

基于合宙 **LuatOS CORE-ESP32-C3** 的新固件。原草图的脱敏副本 `reference/network-clock.ino` 与 `m202md28aa.h` 保留为功能和已点亮屏幕的协议参考，不参与 PlatformIO 构建。本地原始 `network-clock.ino` 含历史账号信息，已忽略，不提交到远程。

## 当前实现

- 日期、时分秒显示，异步 SNTP 校时；默认 UTC+8，可按分钟调整固定 UTC 偏移。
- 内容轮播：第一行保留时间，第二行可选日期、温湿度合并、独立温度和独立湿度；网页调整选择与 5–120 秒停留时间。消息、配网和显示睡眠期间暂停。
- Wi-Fi 自动重试（10 / 20 / 40 / 60 秒）。无配置立即开放配网热点，持续离线 30 秒后开放恢复热点。
- 本地网页设置 Wi-Fi、四档亮度、UTC 偏移、校时服务器与 MQTT 连接；显示设备时间、温湿度、网络状态和运行时间。页面不依赖外网字体、脚本或 CDN。
- 配置以单个有版本和 CRC32 校验的完整记录写入 NVS；成功保存后才发布新设置。参数不合法、保存失败均不改变运行配置。
- AHT10 每 5 秒采样，采用独立状态机，单次 I2C 超时 20ms、测量超时 250ms、故障 10 秒后复位重试；保留并标记最近有效读数。
- 20×2 字格页面，支持 ASCII 与 GB2312 中文，补空格清除残字、按行差分更新。
- 可选 MQTT/TLS 接收消息：8 条内存队列、中文转换、长消息滚动和本机确认；默认关闭，可通过本地网页启用和配置，使用见 [消息说明](docs/mqtt-messages.md)。
- 可选实体按键：短按优先唤醒或确认当前消息，无消息时切换并保存亮度；长按 3 秒重新开放配网热点。默认未启用按键，不假定 GPIO8 是这块板的板载按键。
- 动画引擎与手动显示睡眠/唤醒已实现；雷达、光照驱动、自动灭屏及 MCU 深度睡眠暂未实现。

第一行末尾 `!` 表示 Wi-Fi 离线，第二行末尾 `*` 表示温湿度读取失败或超过 15 秒未更新。没有有效时间时不显示 1970 年日期；没有有效温湿度时显示 `--.-`。联网校时后即使断网仍继续走时，断电重启需要重新校时。

## 网页配网

1. 首次启动且无网络配置时，连接设备提供的 **`W4VFD-Clock-xxxx`** Wi-Fi，后缀为设备 MAC 地址的后四位十六进制字符。
2. 热点密码为设备生成的 **8 位纯数字访问密钥**。未联网且配网热点开放时，屏幕每 8 秒在普通时钟与配网信息间切换；联网成功后立即停止配网信息轮播，配网页第二行显示 `KEY:...`；启动串口日志也会输出该设备访问密钥。家庭 Wi-Fi 密码不会输出到日志。
3. 浏览器手动打开 **`http://192.168.4.1`**，登录用户名 **`admin`**，密码为同一设备访问密钥。当前未实现自动弹出的 captive portal。
4. 填写家庭 Wi-Fi 名称、密码及其他设置，点击“保存并应用”。设备在约 1.5 秒后切换网络，让保存响应先发回浏览器。
5. 联网后可在路由器设备列表（客户端名称与热点同为 `W4VFD-Clock-xxxx`）或串口日志中找到设备 IP，打开 `http://设备IP` 继续管理。

热点最多开放 10 分钟；设备连续联网 60 秒后会提前关闭。每次启动或修改网络配置后，自动恢复热点只开放一轮；过期后可重启设备，或在已配置实体按键时长按重新开放。若手机自动离开无互联网的热点，需在手机上选择保持连接。

访问密钥为 8 位纯数字（可包含前导零），首次初始化时生成并独立保存在 NVS，不会随普通重启改变。升级时旧版 16 位密钥会自动替换为新密钥并保存。当前没有密钥重置页面；清除 NVS 后会重新生成密钥，也会丢失已保存设置。

页面提供“保留原密码 / 填写新密码 / 开放网络”三种明确操作。更换 SSID 时必须填写密码或选择开放网络。API 不返回已保存的 Wi-Fi 密码。MQTT ClientID 和认证密码也不回显，提供保留、替换、清除三种操作；更换服务器、端口或加密方式时，需要明确替换或清除旧凭据。SSID 支持最多 32 字节有效 UTF-8 文本，密码支持 8–63 个 ASCII 字符或 64 位十六进制 PSK。

管理接口采用 HTTP Basic 登录、每次启动生成的 CSRF 令牌、同源资源策略和有限请求体。当前是本地 HTTP 服务，不提供 TLS，适用于设备热点或可信局域网；不要将管理端口映射到公网。网页字段和 NVS 均不提供机密数据加密存储。

## 硬件与构建

板型对应 PlatformIO 的 `airm2m_core_esp32c3`，采用 **DIO** Flash 配置。参考 [合宙板级资料](https://wiki.luatos.com/chips/esp32c3/board.html) 与已安装 Arduino variant：默认 SDA=GPIO4、SCL=GPIO5。原代码的 `aht.begin()` 未显式传引脚，会使用编译时板型的默认 I2C 引脚；现在按用户确认的 LuatOS 板型启用 GPIO4/5。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `CLOCK_VFD_TX` | GPIO0 | 来自已点亮参考代码，9600 baud、8N1；VFD 接收引脚不需要连接到 MCU RX |
| `CLOCK_I2C_SDA` / `CLOCK_I2C_SCL` | GPIO4 / GPIO5 | AHT10 地址 0x38；同时设为 -1 可禁用 |
| `CLOCK_BUTTON_PIN` | -1 | 可选外接按键，启用后使用上拉、低电平按下 |
| `CLOCK_WIFI_SSID` / `CLOCK_WIFI_PASSWORD` | 空 | 可选编译时默认值；NVS 已保存设置优先 |

如需覆盖引脚或提供默认网络，复制 `include/local_config.example.h` 为 `include/local_config.h`。该文件已被 Git 忽略；编译时凭据会进入固件，勿分发含个人凭据的固件文件。网页保存的网络配置不需要重新编译。

```sh
pio run -e esp32c3
```

默认环境适用于通过外置 USB-UART 芯片连接 UART0（GPIO20/21）的版本。对于 USB 直接连接 GPIO18/19 的版本，使用：

```sh
pio run -e esp32c3-usb
```

两者均使用 LuatOS 板型、UART1 向 GPIO0 输出屏幕数据。根据实物 USB 接线选择环境，避免日志与接口配置不匹配。未确认连接到实物前不执行烧录。本批没有执行烧录。

构建固定使用 `espressif32@8.0.0`、Arduino-ESP32 3.3.12。使用框架自带 `min_spiffs.csv` 4MB 分区布局：双 0x1E0000 应用槽，为后续 OTA 预留空间。**本批尚未实现 OTA**。相较第一批改变了分区布局，首次升级本批应通过串口完整烧录，包含分区表。

## 结构与并发

- `core.h` / `aht10.h`：页面、显示输出、按键、传感器状态机，均可在主机测试。
- `settings.h`：配置校验、严格表单解析、UTF-8 检查、版本化序列化与 CRC32。禁止重复/未知字段、NUL 注入及非法长度。
- `network_policy.h`：可测试的重试、配网窗口、恢复与关闭策略。
- `rotation.h`：独立持久化、轮播状态机与真实数据页面；阅读计时从页面完成入场且排空 UART 后开始。
- `mqtt_settings.h`：MQTT 表单校验、凭据保留与独立 CRC 记录；服务器变化时要求明确替换或清除旧凭据。
- `messages.h` / `gb2312_table.h`：固定容量消息队列、严格 UTF-8 转码、按字格滚动与确认。转码表由 `scripts/generate_gb2312.py` 生成。
- `mqtt_service.cpp`：独立 FreeRTOS 接收任务，连接与 TLS 等待不占用时钟主循环；固定队列向主循环交付消息。
- `network.cpp`：Wi-Fi 适配，只在主循环中运行；网络配置应用延迟独立于保存。
- `portal.cpp`：ESP-IDF HTTP 服务，运行在独立 FreeRTOS 任务，限制普通设置请求体 1024 字节、MQTT 请求体 2048 字节及接收超时。慢浏览器不会在时钟主循环中等待。
- `main.cpp`：硬件初始化与业务调度。HTTP 和主循环间仅在短临界区复制固定大小快照；NVS 写操作通过独立互斥锁串行化，主循环按键保存遇忙时立即返回。
- `web/`：网页源文件；`scripts/embed_web.py` 在编译前生成 `include/clock/web_assets.h`。不要直接编辑生成文件。

实物验收：

1. 空配置启动，热点名称与密码可用，登录需要设备密钥，页面可在无外网环境加载。
2. 保存正确网络并联网，设置重启后保留，热点在连续联网 60 秒后关闭。
3. 保存错误网络，30 秒后仍可通过热点修正；热点过期后可重启或长按重新开启。
4. 修改亮度、UTC 偏移与 NTP 后自动生效；保留密码模式不会清空原密码。
5. 非法参数、缺字段、重复字段、无登录或无有效 CSRF 令牌的请求不能修改配置。
6. 拔下 AHT10、持续访问或慢速请求页面时，时钟继续刷新；重新接回 AHT10 后自动恢复。
7. 若启用按键，无消息时短按只改变一档；有消息时确认当前消息，睡眠时先唤醒；长按只触发配网。
8. 启用 MQTT 后验证 TLS 连接、断网重连、中文与长消息、队列满和重复消息；旧确认请求不能清除下一条消息。睡眠和配网期间只缓存，返回普通显示后再展示。

## 内容轮播与管理

管理页“内容轮播”提供四项选择，按日期与星期、室内温湿度、独立温度、独立湿度的固定顺序展示。默认轮播前两项，每页 8 秒；至少保留一项，只选一项时固定显示。停留时间统一可设 5–120 秒，当前不支持拖动排序或为每项单独设时长。

时间始终保留在第一行，第二行换页使用现有推入动画；日期未校准时明确显示不可用，传感器故障时保留最后读数并标记 `*`，从未有过有效数据时显示占位符。不会为天气、股票或未接入传感器构造模拟读数。

页面完成入场且 UART 排空后才开始计算阅读时间，普通数值刷新不重置计时。消息（含确认反馈）、配网热点或显示睡眠会暂停轮播；退出优先场景后恢复原页，并给该页完整停留时间。修改设置成功后从所选第一项开始。设置使用独立 `rotation` NVS 记录（11 字节，版本 1、CRC32），保存失败不改变配置；无记录或损坏时使用默认值，不修改原 Wi-Fi / MQTT 记录。

网页轮询只更新运行状态，不覆盖尚未提交的编辑。`POST /api/rotation` 只接受 `pages`（位掩码 1/2/4/8，可组合）与 `hold`（秒）两个字段，沿用设备登录和 CSRF 校验；页面不允许取消全部内容，设备也会拒绝空选择。
